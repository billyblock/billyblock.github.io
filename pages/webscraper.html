NBA Salary by Country

Web Scraper | Data Visualization

Scrapes NBA player nationalities and salaries from multiple websites, combines the datasets, and visualizes average player salary by country.

Python Selenium Matplotlib
View on GitHub

Project Overview

This project uses Python and Selenium to navigate webpages, extract the data, and store it as JSON, then visualizes the results with Matplotlib.

Features:

  • Scrapes player names and nationalities from RealGM.
  • Scrapes player salaries from HoopsHype.
  • Matches names across both data sources.
  • Stores the collected data in JSON files.
  • Calculates the average salary by country.
  • Generates a bar chart of the top earning countries.
